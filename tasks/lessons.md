# Project lessons

- Accept any ChatGPT account for sign-in; never turn the tester's plan tier into a product restriction. Validate the granted permission and let OpenAI determine model and plan eligibility.
- Confirm the effective provider and auth mode after saving user settings; project, command-line and managed settings can override them. Respect host-owned routing instead of reporting a false billing-mode switch.
- Check earlier signal listeners when adding cancellation to a subcommand. A global synchronous exit can preempt an otherwise correct abort/finally path.

- Verify the filesystem and actual package scripts before trusting the repository overview: this extracted snapshot had missing modules, incomplete package aliases and no Git history.
- Equal React versions can still be separate runtime module instances. Check identity from the renderer's resolution context before diagnosing invalid hooks as application logic.
- Check the complete CI shell contract, including `pipefail` and inherited `-e`, before claiming a pipeline masks test failures.
- Keep native Responses metadata once per assistant response, then associate normalized siblings during conversion. Deduplicate replay and reject partial edits that would restore removed content.
- Keep subscription billing mode selected after logout. Removing credentials must not activate an older API key.
- Use actual account catalog limits before local context suffixes; a `[1m]` UI marker cannot grant a model a larger context window.
- Distinguish focused fixture-backed proofs, full repository results and live account acceptance. Do not label unverified failures as pre-existing or report mocked inference as live subscription access.
